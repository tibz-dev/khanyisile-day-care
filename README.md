# Khanyisile Day Care and Extra Classes

A single React + TypeScript website built with Vite.

## Architecture

- One repository containing one frontend application.

## Local development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run format:check
npm run lint
npm run build
```

## Formatting

```bash
npm run format
```

## Production preview

```bash
npm run build
npm run preview
```

## Source folders

- components: Shared interface components.
- pages: Website pages.
- assets: Images, logos, and other bundled assets.
- styles: Global styles.
- hooks: Reusable React hooks.
- types: Shared TypeScript types.
- utils: Utility functions.
